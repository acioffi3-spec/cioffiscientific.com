// dataset a

Quality control and drift correction across a 428-injection plasma study

Commercial plasma, serum, and a pooled QC run on a 5-minute SWATH method throughout a large serum study (Messner et al., Cell Systems 2020; PRIDE PXD018874), processed with DIA-NN. Each matrix is one pooled material pipetted into many wells, so all within-matrix variation is technical. That gives normalization an objective target, and fibrinogen, which clotting removes from serum, gives a built-in positive control.

Inherited filters audited and a global protein-group rule justified; identification depth, missingness structure, CVs, retention-time stability, plate-map QC, and a drift analysis showing the signal loss is retention-time dependent and non-linear.

// dataset b

Calibrating differential abundance against known truth

Hybrid-proteome LFQ benchmark (Van Puyvelde et al., Sci Data 2022; PRIDE PXD028735). Human, yeast, and E. coli digests are mixed at defined ratios, so the true log2 fold changes are known (human 0, yeast +1, E. coli −2), and statistical choices can be graded, not just asserted.
